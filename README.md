# Sonu Kumar Productions

Edit `dist/index.html` to add your bio and work highlights. In each profile card, replace the pending message with a link to your verified YouTube, Instagram, or author profile.

Preview locally with `python3 -m http.server 8000 --bind 127.0.0.1 --directory dist`, then open [localhost:8000](http://127.0.0.1:8000).
